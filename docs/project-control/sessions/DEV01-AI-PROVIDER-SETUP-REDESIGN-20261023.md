## Problem and desired product behavior

Before the change, the same list of compatible providers was rendered as small status cards with Select buttons **and** a second vendor dropdown. A provider was preselected even if the user had not chosen it; status text such as “key enabled” could be mistaken for a fully configured AI capability. Voice TTS/STT and Realtime keys are independent records but were visually easy to confuse. An unsuccessful organization GET left a persistent spinner.

For employees, small-business users and administrators, selection should start with **what the AI needs to do** rather than a misleading globally selected vendor; show only compatible providers per job, present one explicit vendor selector, reveal a guided configuration panel only for a chosen vendor, distinguish saved credentials from saved models and real provider availability, and preserve secure credentials and API permission boundaries.
